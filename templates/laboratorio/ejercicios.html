Merge Sort: divide, ordena y combina

Ordenar una lista larga es difícil, pero ordenar una lista de un solo elemento es trivial: ¡ya está ordenada! Merge Sort aprovecha esa idea. Parte la lista en mitades cada vez más pequeñas y después las vuelve a unir, siempre en orden.

Cómo funciona

  1. Dividir. Parte la lista por la mitad. Repite lo mismo con cada mitad hasta que todas las partes tengan un solo elemento.
  2. Caso base. Una parte con un solo elemento ya está ordenada; no hay nada que hacer.
  3. Combinar. Une dos partes ordenadas mirando solo el primer elemento de cada una: el menor pasa al resultado. Repite hasta vaciar ambas partes.
  4. Al combinar todas las parejas, de abajo hacia arriba, se obtiene la lista completa ordenada.

Piénsalo así: si tienes dos montones de cartas ya ordenados boca arriba, para unirlos solo necesitas comparar las dos cartas de arriba y tomar la menor, una y otra vez.

Conceptos

Divide y vencerás: resolver un problema grande partiéndolo en problemas pequeños del mismo tipo. Recursividad: la función se llama a sí misma con cada mitad. Caso base: una lista de 0 o 1 elementos ya está ordenada. Estabilidad: ante valores iguales se toma primero el de la izquierda, así se conserva su orden original. Complejidad: tiempo O(n log n) en todos los casos y espacio auxiliar O(n).
