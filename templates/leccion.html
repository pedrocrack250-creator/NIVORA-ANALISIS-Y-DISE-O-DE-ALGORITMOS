Antes del quiz

{% if lesson.id == 'variables' %}

Una variable guarda un valor. Python tiene tipos como str, int, float y bool.

nombre = "Ana"
edad = 20
activo = True
{% elif lesson.id == 'operadores' %}

Los operadores permiten calcular y comparar valores.

suma = 3 + 4
mayor = 5 > 2
{% elif lesson.id == 'entrada_salida' %}

print muestra información y input recibe texto.

nombre = input("Tu nombre: ")
print(nombre)
{% elif lesson.id == 'condicionales' %}

if ejecuta un bloque solo cuando la condición es verdadera; else se ejecuta en caso contrario. La sangría indica qué instrucciones pertenecen a cada bloque.

edad = 17
if edad >= 18:
    print("Puedes votar")
else:
    print("Todavía no puedes votar")
{% elif lesson.id == 'elif' %}

elif evalúa otra condición si las anteriores fueron falsas. Solo se ejecuta el primer bloque cuya condición se cumpla. Con and y or combinas condiciones.

nota = 8
if nota >= 9:
    print("Excelente")
elif nota >= 6 and nota < 9:
    print("Aprobado")
else:
    print("Reprobado")
{% elif lesson.id == 'ciclo_for' %}

for repite un bloque para cada elemento de una secuencia. range(n) genera los números de 0 a n - 1.

for i in range(3):
    print(i)        # 0, 1, 2

for fruta in ["manzana", "pera"]:
    print(fruta)
{% elif lesson.id == 'ciclo_while' %}

while repite mientras su condición sea verdadera. break termina el ciclo y continue salta a la siguiente vuelta.

contador = 0
while contador < 5:
    contador += 1
    if contador == 2:
        continue
    if contador == 4:
        break
    print(contador)  # 1, 3
{% elif lesson.id == 'listas' %}

Una lista guarda varios valores en orden. Cada elemento tiene un índice que empieza en 0; los índices negativos cuentan desde el final.

numeros = [10, 20, 30]
print(numeros[0])   # 10
print(numeros[-1])  # 30
{% elif lesson.id == 'metodos_listas' %}

Los métodos modifican la lista: append agrega, remove elimina un valor, pop quita el último elemento y sort ordena.

numeros = [3, 1, 2]
numeros.append(5)
numeros.remove(1)
ultimo = numeros.pop()  # 5
numeros.sort()          # [2, 3]
{% elif lesson.id == 'tuplas' %}

Una tupla se escribe entre paréntesis y, a diferencia de una lista, no se puede modificar después de crearla.

punto = (4, 8)
print(punto[0])  # 4
# punto[0] = 1   -> error: las tuplas son inmutables
{% elif lesson.id == 'diccionarios' %}

Un diccionario guarda pares clave-valor entre llaves. Se accede a cada valor mediante su clave.

persona = {"nombre": "Ana", "edad": 20}
print(persona["edad"])   # 20
print(persona.keys())    # nombre, edad
{% elif lesson.id == 'definir_funciones' %}

Una función agrupa instrucciones con un nombre. Se define con def, termina la línea con : y se ejecuta escribiendo su nombre con paréntesis.

def saludar():
    print("¡Hola!")

saludar()
{% elif lesson.id == 'parametros' %}

Los parámetros son los nombres que recibe la función; los argumentos son los valores que envías al llamarla. Un parámetro puede tener un valor por defecto.

def sumar(a, b):
    print(a + b)

def saludar(saludo="Hola"):
    print(saludo)

sumar(2, 3)   # 5
saludar()     # Hola
{% elif lesson.id == 'retorno' %}

return devuelve un resultado para usarlo después. Si una función no tiene return, devuelve None.

def doble(n):
    return n * 2

resultado = doble(4)  # 8
{% elif lesson.id == 'repaso_funciones' %}

Las variables creadas dentro de una función solo existen dentro de ella. Una función también puede llamarse a sí misma: se dice que es recursiva.

def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(4))  # 24
{% else %}

Las listas agrupan valores. Puedes consultar su tamaño y agregar elementos.

frutas = ["manzana"]
frutas.append("pera")
{% endif %}
